# Changelog

Notable changes to NetGraph are recorded here. This project has not yet published tagged releases; the initial entry summarizes the repository state documented on 2026-10-22.

## Unreleased

- No unreleased changes recorded.

## 1.0.0 — 2026-10-22

- Added cross-platform local IPv4 network detection for Windows and Linux.
- Added ping and ARP/neighbour-table device discovery.
- Added a gateway-centred graph model and BFS, DFS, Dijkstra, and A* algorithms.
- Added browser and terminal interfaces, device search and sorting, and benchmark reports for web algorithm runs.
- Documented setup, usage, architecture, limitations, and citation metadata.
